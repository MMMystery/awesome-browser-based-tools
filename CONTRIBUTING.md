# Contributing

Thanks for helping improve **Awesome Browser-Based Tools**.

This repository is a curated list, not a paid directory. Please keep submissions useful, specific, and relevant to people looking for tools that work directly in a browser.

## What We Accept

Good submissions usually match several of these points:

- The tool works from a browser without desktop installation.
- The tool solves a specific task clearly.
- The URL is stable and uses HTTPS.
- The landing page makes pricing, privacy, and limitations reasonably clear.
- The tool is useful to designers, developers, writers, creators, analysts, or everyday web users.

## What We Reject

We may reject submissions that are:

- Thin affiliate pages or low-effort landing pages.
- Gambling, adult, spam, or crypto lead-gen tools.
- Mostly hidden behind a signup wall.
- Unrelated to browser-based workflows.
- Repeated across too many categories.
- Written with exaggerated marketing claims.

## Entry Format

Use this format:

```md
- [Tool Name](https://example.com/) - One clear sentence explaining what it does. `tag-one` `tag-two`
```

Guidelines:

- Keep descriptions neutral and factual.
- Do not use tracking parameters in URLs.
- Prefer the product homepage or exact tool page.
- Add only tags already used in the README unless a new tag is clearly needed.
- Place the entry under the most relevant category.

## Pull Request Checklist

Before opening a PR:

- [ ] I checked that the tool is not already listed.
- [ ] The tool works in a browser.
- [ ] The URL loads over HTTPS.
- [ ] The description is short, factual, and not promotional.
- [ ] I added the tool to only one or two relevant categories.

## Maintainer Disclosure

This list is maintained by the maker of [24Picture](https://24picture.com) and [ToolKnit](https://toolknit.com). Those projects may appear in the list when relevant, and third-party submissions are welcome.

## Reporting Issues

If a listed tool is dead, unsafe, misleading, or has changed focus, please open an issue with the tool name and URL.
